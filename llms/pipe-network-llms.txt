# Pipe Network

> Pipe Network is a decentralized storage and content-delivery network built on Solana ("Firestarter" storage). It offers content-addressed (Blake3) object storage with client-side and post-quantum encryption, deterministic public URLs, prepaid-USDC billing, and first-party SDKs/CLI plus native agent-framework tool adapters and x402 machine payments.

Generated by the API Evangelist enrichment pipeline (method: generated) on 2026-07-20 from the provider's public GitHub org and docs. Not a provider-published llms.txt.

## Core surface

- Base URL (default storage node): https://us-west-01-firestarter.pipenetwork.com
- Deterministic object URL: https://{node}/{account}/{hash}
- Auth: SIWS (Sign In With Solana) -> JWT bearer; or user_app_key query param
- SDK operations: auth_challenge, auth_verify, auth_refresh, auth_logout, store, fetch, pin, delete, /user/me
- CDN API endpoints: POST /createUser, POST /rotateAppKey, POST /upload, GET /download, GET /checkBalance
